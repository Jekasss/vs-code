# Предполагаемый процесс обработки входящего документа

## 1. Назначение процесса

Процесс предназначен для регистрации и рассмотрения входящего документа, подготовки и согласования ответа, регистрации и подписания исходящего документа, а также его последующей отправки получателю.

Процесс начинается после регистрации входящего документа ведущим юрисконсультом Службы юридического сопровождения и организации деятельности (далее — СЮСОИД) и завершается после отправки ответа получателю.

## 2. Участники процесса

| Участник                                                                   | Функция в процессе                                                                                                                                                                                                                                                                                     |
| ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ведущий юрисконсульт СЮСОИД                               | Создаёт и регистрирует входящий документ; регистрирует исходящий документ; направляет ответ получателю, если выбран неэлектронный способ отправки                                       |
| Директор ФЦИИТ                                                        | Рассматривает входящий документ; назначает исполнителей; при необходимости назначает сотрудников для ознакомления; подписывает исходящий документ                                     |
| Исполнитель из списка 1 «Администрация»          | Самостоятельно подготавливает ответ на входящий документ                                                                                                                                                                                                            |
| Исполнитель из списка 2 «Руководители служб» | Самостоятельно подготавливает ответ либо делегирует подготовку одному или двум подчинённым                                                                                                                                            |
| Ответственный руководитель                                | При назначении директором двух руководителей контролирует подготовку итогового проекта ответа, делегирует задачу своему подчинённому и согласовывает итоговый проект |
| Руководитель-соисполнитель                                | При назначении директором двух руководителей организует подготовку фактуры своим подчинённым и согласовывает подготовленные материалы                                                          |
| Подчинённый — ответственный исполнитель        | Подготавливает проект ответа либо итоговый проект ответа с учётом материалов соисполнителя                                                                                                                                             |
| Подчинённый — соисполнитель                               | Подготавливает фактуру или материалы для итогового проекта ответа                                                                                                                                                                                            |
| Руководитель, делегировавший выполнение        | Согласовывает проект ответа, подготовленный подчинённым                                                                                                                                                                                                              |
| Руководитель СЮСОИД                                              | Согласовывает проект исходящего документа перед регистрацией                                                                                                                                                                                                    |
| Дополнительный согласующий                                | Согласовывает проект ответа, если был включён исполнителем в состав согласующих                                                                                                                                                                   |
| Сотрудник, назначенный для ознакомления         | Выполняет задачу`Ознакомиться`                                                                                                                                                                                                                                                            |

## 3. Начало процесса

1. Ведущий юрисконсульт СЮСОИД создаёт входящий документ.
2. Ведущий юрисконсульт СЮСОИД регистрирует входящий документ.
3. После регистрации система автоматически запускает процесс обработки входящего документа.
4. Директору ФЦИИТ создаётся задача `Рассмотреть`.

## 4. Рассмотрение директором ФЦИИТ

При выполнении задачи `Рассмотреть` директор ФЦИИТ:

1. изучает входящий документ;
2. назначает одного исполнителя из списка 1 «Администрация» или списка 2 «Руководители служб» либо двух руководителей в любой из допустимых комбинаций списков;
3. если назначены два руководителя, определяет одного из них ответственным, а второго — соисполнителем;
4. при необходимости выбирает сотрудников, которым требуется ознакомиться с документом;
5. завершает задачу `Рассмотреть`.

Для каждого сотрудника, выбранного для ознакомления, создаётся отдельная задача `Ознакомиться`. Задачи ознакомления выполняются параллельно основному маршруту подготовки ответа.

Дальнейший маршрут подготовки ответа зависит от того, к какому списку относится выбранный исполнитель и каким способом будет организовано исполнение.

## 5. Сценарий 1. Выбран исполнитель из списка 1 «Администрация»

### 5.1. Создание исходящего документа

После завершения директором задачи `Рассмотреть` система:

1. автоматически создаёт исходящий документ, связанный с обрабатываемым входящим документом;
2. заполняет реквизит `Исполнитель` сотрудником, которого выбрал директор ФЦИИТ;
3. создаёт выбранному исполнителю задачу `Подготовить ответ`.

### 5.2. Подготовка ответа

Исполнитель:

1. открывает созданный исходящий документ;
2. подготавливает и заполняет проект ответа;
3. при необходимости определяет состав дополнительных согласующих;
4. завершает задачу `Подготовить ответ`.

### 5.3. Согласование

После завершения задачи `Подготовить ответ`:

1. проект направляется дополнительным согласующим, если они были указаны исполнителем;
2. руководителю СЮСОИД создаётся задача `Согласовать`;
3. после завершения согласования проект переходит на общий завершающий маршрут, описанный в разделе 9.

## 6. Сценарий 2. Выбран исполнитель из списка 2 «Руководители служб»

После завершения директором задачи `Рассмотреть` система:

1. автоматически создаёт исходящий документ, связанный с обрабатываемым входящим документом;
2. заполняет реквизит `Исполнитель` руководителем, которого выбрал директор ФЦИИТ;
3. создаёт выбранному руководителю задачу `Подготовить ответ`.

Выбранный руководитель может подготовить ответ самостоятельно либо делегировать подготовку одному или двум подчинённым.

### 6.1. Сценарий 2.1. Руководитель подготавливает ответ самостоятельно

1. Выбранный руководитель подготавливает проект ответа в исходящем документе.
2. При необходимости руководитель определяет состав дополнительных согласующих.
3. Руководитель завершает задачу `Подготовить ответ`.
4. Проект направляется дополнительным согласующим, если они были указаны.
5. Руководителю СЮСОИД создаётся задача `Согласовать`.
6. Если ответ самостоятельно подготовил руководитель СЮСОИД, отдельная задача согласования руководителю СЮСОИД не создаётся, и проект сразу переходит на общий завершающий маршрут.
7. После завершения согласования проект переходит на общий завершающий маршрут, описанный в разделе 9.

### 6.2. Сценарий 2.2. Руководитель делегирует подготовку одному подчинённому

1. Выбранный директором руководитель назначает исполнителем одного подчинённого.
2. Задача `Подготовить ответ` перенаправляется от руководителя назначенному подчинённому штатным механизмом 1С:Документооборота.
3. Подчинённый подготавливает проект ответа и завершает задачу.
4. Руководителю, делегировавшему выполнение, создаётся задача `Согласовать`.
5. Руководитель проверяет подготовленный проект и завершает задачу согласования.
6. После согласования руководителем руководителю СЮСОИД создаётся задача `Согласовать`.
7. Если руководителем, делегировавшим выполнение, является руководитель СЮСОИД, повторная задача согласования руководителю СЮСОИД не создаётся.
8. После завершения согласования проект переходит на общий завершающий маршрут, описанный в разделе 9.

### 6.3. Сценарий 2.3. Руководитель делегирует подготовку двум подчинённым

Выбранный директором руководитель назначает:

- одного подчинённого ответственным исполнителем;
- второго подчинённого соисполнителем.

Система создаёт две параллельные задачи:

| Получатель                              | Задача                                                          | Результат выполнения                                                                                                                      |
| ------------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Соисполнитель                        | `Подготовить фактуру`                             | Подготовленные материалы или часть ответа переданы ответственному исполнителю          |
| Ответственный исполнитель | `Подготовить итоговый проект ответа` | Сформирован итоговый проект исходящего документа с учётом материалов соисполнителя |

Порядок выполнения:

1. Соисполнитель первым завершает задачу `Подготовить фактуру`.
2. Подготовленные соисполнителем материалы прикладываются во вложенные файлы исходящего документа и становятся доступны ответственному исполнителю.
3. Ответственный исполнитель использует полученные материалы при подготовке итогового проекта ответа.
4. Штатный механизм 1С:Документооборота не позволяет ответственному исполнителю завершить задачу `Подготовить итоговый проект ответа` до завершения задачи соисполнителя.
5. Ответственный исполнитель завершает задачу `Подготовить итоговый проект ответа` после поступления и обработки материалов соисполнителя.
6. Руководителю, делегировавшему выполнение, создаётся задача `Согласовать`.
7. Руководитель проверяет итоговый проект и завершает задачу согласования.
8. После согласования руководителем руководителю СЮСОИД создаётся задача `Согласовать`.
9. Если руководителем, делегировавшим выполнение, является руководитель СЮСОИД, повторная задача согласования руководителю СЮСОИД не создаётся.
10. После завершения согласования проект переходит на общий завершающий маршрут, описанный в разделе 9.

## 7. Сценарий 3. Директор назначает двух руководителей

### 7.1. Назначение ролей и создание задач

При рассмотрении входящего документа директор ФЦИИТ может выбрать двух руководителей в одной из следующих комбинаций:

- двух руководителей из списка 1 «Администрация»;
- двух руководителей из списка 2 «Руководители служб»;
- одного руководителя из списка 1 «Администрация» и одного руководителя из списка 2 «Руководители служб».

Независимо от выбранной комбинации директор определяет роли участников:

- один руководитель назначается ответственным и контролирует подготовку итогового проекта ответа;
- второй руководитель назначается соисполнителем и отвечает за подготовку фактуры или материалов для ответа.

Выбранная комбинация списков не изменяет дальнейший маршрут обработки документа.

После завершения директором задачи `Рассмотреть` система:

1. автоматически создаёт один исходящий документ, связанный с обрабатываемым входящим документом;
2. заполняет в исходящем документе обоих выбранных руководителей в качестве исполнителей;
3. создаёт ответственному руководителю задачу `Подготовить итоговый проект ответа` с ролью контролирующего;
4. создаёт руководителю-соисполнителю задачу `Подготовить фактуру` с ролью соисполнителя.

Обе задачи создаются одновременно. Штатный механизм 1С:Документооборота не позволяет завершить задачу ответственного исполнителя до завершения задачи соисполнителя. Сначала должна быть подготовлена и согласована фактура, после чего завершается подготовка итогового проекта ответа.

### 7.2. Делегирование задач руководителями

1. Руководитель-соисполнитель перенаправляет задачу подготовки фактуры своему подчинённому штатным механизмом 1С:Документооборота.
2. Ответственный руководитель перенаправляет задачу подготовки итогового проекта ответа своему подчинённому штатным механизмом 1С:Документооборота.
3. Подчинённый руководителя-соисполнителя становится подчинённым-соисполнителем.
4. Подчинённый ответственного руководителя становится подчинённым-ответственным исполнителем.

При делегировании сохраняются роли руководителей: руководитель-соисполнитель отвечает за согласование фактуры, а ответственный руководитель — за согласование итогового проекта ответа.

### 7.3. Подготовка и согласование фактуры

1. Первым выполняет задачу подчинённый-соисполнитель.
2. Подчинённый-соисполнитель подготавливает фактуру или материалы для ответа и прикладывает их во вложенные файлы исходящего документа.
3. После подготовки материалов подчинённый-соисполнитель завершает задачу.
4. Руководителю-соисполнителю создаётся задача `Согласовать фактуру`.
5. Руководитель-соисполнитель проверяет подготовленные материалы и завершает задачу согласования.
6. После согласования вложенные файлы с фактурой становятся доступны подчинённому-ответственному исполнителю.

### 7.4. Подготовка и согласование итогового проекта ответа

1. После согласования фактуры подчинённый-ответственный исполнитель выполняет задачу `Подготовить итоговый проект ответа`.
2. Подчинённый-ответственный исполнитель использует согласованную фактуру при подготовке итогового проекта исходящего документа.
3. После подготовки проекта подчинённый-ответственный исполнитель завершает задачу.
4. Ответственному руководителю создаётся задача `Согласовать итоговый проект ответа`.
5. Ответственный руководитель проверяет итоговый проект и завершает задачу согласования.
6. После согласования ответственным руководителем проект передаётся руководителю СЮСОИД.

### 7.5. Переход на общий маршрут

1. Руководителю СЮСОИД создаётся задача `Согласовать`.
2. Если ответственным руководителем является руководитель СЮСОИД, отдельная задача согласования руководителю СЮСОИД не создаётся, и этот этап пропускается.
3. После согласования руководителем СЮСОИД либо пропуска этого этапа проект переходит на общий завершающий маршрут, описанный в разделе 9.

## 8. Дополнительные согласующие

Дополнительные согласующие могут быть назначены только исполнителем из списка 1 «Администрация» в сценарии 1. В сценариях 2 и 3 дополнительные согласующие не используются.

Если в сценарии 1 дополнительные согласующие указаны, проект должен пройти их согласование до передачи руководителю СЮСОИД.

## 9. Общий завершающий маршрут

Общий завершающий маршрут применяется после подготовки проекта и выполнения всех предусмотренных сценарием согласований.

### 9.1. Регистрация исходящего документа

1. Ведущему юрисконсульту СЮСОИД создаётся задача `Зарегистрировать`.
2. Ведущий юрисконсульт регистрирует исходящий документ.
3. Ведущий юрисконсульт завершает задачу `Зарегистрировать`.

### 9.2. Подписание исходящего документа

1. После регистрации директору ФЦИИТ создаётся задача `Подписать`.
2. Директор подписывает исходящий документ.
3. Директор завершает задачу `Подписать`.

### 9.3. Отправка по электронной почте

Если в исходящем документе выбран способ отправки `E-mail`:

1. после подписания система автоматически формирует и отправляет письмо получателю;
2. отдельная задача на отправку ведущему юрисконсульту не создаётся;
3. после успешной отправки процесс обработки входящего документа завершается.

### 9.4. Отправка иным способом

Если в исходящем документе выбран любой способ отправки, отличный от `E-mail`:

1. ведущему юрисконсульту СЮСОИД создаётся задача `Направить документ`;
2. ведущий юрисконсульт направляет документ получателю выбранным способом;
3. ведущий юрисконсульт завершает задачу `Направить документ`;
4. после завершения задачи процесс обработки входящего документа завершается.

## 10. Результат процесса

В результате выполнения процесса:

- входящий документ зарегистрирован и рассмотрен директором ФЦИИТ;
- определён исполнитель или состав исполнителей;
- при необходимости сотрудники ознакомлены с входящим документом;
- создан и подготовлен связанный исходящий документ;
- проект ответа прошёл предусмотренные сценарием согласования;
- исходящий документ зарегистрирован и подписан;
- ответ отправлен получателю;
- процесс обработки входящего документа завершён.

## 11. Открытые вопросы

1. Как должен обрабатываться отрицательный результат или возврат документа на доработку на этапах дополнительного согласования, согласования руководителем, согласования руководителем СЮСОИД, регистрации и подписания директором ФЦИИТ?
2. Что должна делать система при ошибке автоматической отправки ответа по электронной почте: повторить отправку, создать задачу ведущему юрисконсульту или перевести процесс в специальное состояние ошибки?
3. Как должен завершаться процесс, если входящий документ не требует подготовки ответа и директор назначает сотрудников только для ознакомления?
