# Настройка правила обработки документа «Материалы для правления по наградам»

Инструкция подготовлена для «1С:Документооборот 3.0» по схеме Section 165 из файла [«Вн. документы. Маршрут 5.pdf»](Вн.%20документы.%20Маршрут%205.pdf).

## 1. Правильная последовательность

Цифра, указанная на исходной схеме, в маршруте не учитывается.

```text
Старт
  ↓
Задача «Вынести вопрос на правление»
  ↓
Правлением принято положительное решение?
  │
  ├─ Нет → Ознакомиться с документом
  │          Санакоева Елена Юрьевна
  │          ↓
  │        Завершение
  │
  └─ Да → Приложить выписку из протокола
             Аветисян Наталья Витальевна
             ↓
           Ознакомиться с документом
             Заярная Юлия Николаевна
             ↓
           Завершение
```

Важно: ознакомления Санакоевой и Заярной не являются двумя последовательными этапами. Они находятся в разных ветвях:

- Санакоева Е. Ю. знакомится с документом только при отрицательном решении;
- Заярная Ю. Н. знакомится с документом только после того, как при положительном решении Аветисян Н. В. приложит выписку из протокола.

## 2. Ветвление по результату задачи

Дополнительный реквизит документа для этого маршрута не нужен. Ветвь можно выбрать по результату выполнения первого действия.

Обычное действие типа `Исполнение` для этой развилки не подходит: исполнитель штатно завершает его командой `Исполнено`, а произвольная пара конечных результатов в карточке вида действия не настраивается.

Для ветвления без дополнительного реквизита создайте действие с наименованием «Вынести вопрос на правление», но с типом `Утверждение`. Если в вашей методике решение правления трактуется как согласование, можно выбрать тип `Согласование`.

Ответственный сотрудник получает задачу и при её завершении выбирает один из двух штатных результатов:

- `Положительный`;
- `Отрицательный`.

Для `Утверждения` это будут результаты вроде `Утверждено` / `Не утверждено`, а для `Согласования` — `Согласовано` / `Не согласовано`. Точный текст команд зависит от релиза.

## 3. Создать или проверить вид документа

1. Откройте `НСИ → Виды документов`.
2. Найдите вид `Материалы для правления по наградам`.
3. Если вида ещё нет, создайте его:
   - тип — `Внутренний документ`;
   - наименование — `Материалы для правления по наградам`;
   - регистрация, доступ и форма документа — по внутреннему регламенту.
4. Запишите вид документа.

## 4. Создать правило обработки

1. В карточке вида документа откройте вкладку `Обработка` или `Правила обработки`.
2. Создайте новое правило.
3. Заполните:
   - наименование — `Материалы для правления по наградам`;
   - тип объекта — `Документы предприятия`;
   - вид документа — `Материалы для правления по наградам`;
   - ответственный — владелец регламента;
   - способ запуска — для тестирования `Интерактивно`.
4. На время настройки не переводите правило в действующее состояние.

## 5. Добавить действие «Вынести вопрос на правление»

Настройте первое действие:

- тип — `Утверждение` (рекомендуется) или `Согласование`;
- наименование — `Вынести вопрос на правление`;
- текст задачи — `Вынести вопрос на правление. После рассмотрения указать, утверждён ли вопрос`;
- предмет — текущий документ;
- исполнитель — согласно внутреннему регламенту;
- условие старта — без условия, сразу после запуска обработки;
- срок — по внутреннему регламенту;
- штатные результаты — положительный и отрицательный результаты выбранного типа действия.

После выбора результата задача завершается, а система проверяет условия следующих действий.

## 6. Создать условия маршрутизации

Создайте два отдельных условия.

### Условие «Положительный результат»

- источник данных — предыдущее действие «Вынести вопрос на правление»;
- проверяемое поле — `Результат выполнения действия`;
- условие:

  ```text
  Результат действия "Вынести вопрос на правление"
  Равно "Положительный"
  ```

### Условие «Отрицательный результат»

- источник данных — предыдущее действие «Вынести вопрос на правление»;
- проверяемое поле — `Результат выполнения действия`;
- условие:

  ```text
  Результат действия "Вынести вопрос на правление"
  Равно "Отрицательный"
  ```

Оба условия должны проверяться сразу после завершения задачи «Вынести вопрос на правление».

## 7. Настроить отрицательную ветвь

При отрицательном решении создайте одно действие:

- тип — `Ознакомление`;
- наименование — `Ознакомиться с документом — Санакоева Е. Ю.`;
- участник — `Санакоева Елена Юрьевна`;
- условие запуска — `Отрицательный результат` предыдущего действия;
- предмет — текущий документ;
- текст задачи — `Ознакомьтесь с документом и отрицательным решением правления`;
- срок — по внутреннему регламенту;
- завершение ветви — после подтверждения ознакомления Санакоевой Е. Ю.

На этой ветви не создаются задача на приложение выписки и задача на ознакомление Заярной.

## 8. Настроить положительную ветвь: приложение выписки

Первое действие положительной ветви:

- тип — `Исполнение`;
- наименование — `Приложить выписку из протокола`;
- исполнитель — `Аветисян Наталья Витальевна`;
- условие запуска — `Положительный результат` предыдущего действия;
- предмет — текущий документ;
- текст задачи — `Приложите выписку из протокола заседания правления`;
- срок — по внутреннему регламенту.

В настройках действия установите:

- обязательность присоединённого файла;
- запрет завершения без выписки;
- при необходимости — вид файла `Выписка из протокола`.

Если типовыми средствами нельзя проверить наличие нужного файла, добавьте алгоритм проверки:

```text
К документу присоединён файл с видом
"Выписка из протокола"
```

## 9. Добавить ознакомление Заярной после выписки

Второе действие положительной ветви:

- тип — `Ознакомление`;
- наименование — `Ознакомиться с документом — Заярная Ю. Н.`;
- участник — `Заярная Юлия Николаевна`;
- порядок — строго после выполнения задачи Аветисян Н. В. «Приложить выписку из протокола»;
- условие — отдельно можно не дублировать, если действие жёстко связано с предыдущим шагом положительной ветви;
- предмет — текущий документ с приложенной выпиской;
- текст задачи — `Ознакомьтесь с документом и приложенной выпиской из протокола`;
- завершение процесса — после подтверждения ознакомления Заярной Ю. Н.

Не настраивайте это ознакомление параллельно с задачей Аветисян: Заярная должна получить документ уже с приложенной выпиской.

## 10. Итоговая таблица действий

| № | Действие | Исполнитель | Условие/порядок |
|---:|---|---|---|
| 1 | Вынести вопрос на правление | по внутреннему регламенту | первое действие |
| 2а | Ознакомиться с документом | Санакоева Е. Ю. | только при отрицательном решении; после задачи процесс завершается |
| 2б | Приложить выписку из протокола | Аветисян Н. В. | только при положительном решении |
| 3б | Ознакомиться с документом | Заярная Ю. Н. | только после выполнения задачи Аветисян; затем процесс завершается |

## 11. Проверить права

Проверьте, что:

- Санакоева Е. Ю. видит документ и может выполнить ознакомление;
- Аветисян Н. В. видит документ и может добавить выписку;
- Заярная Ю. Н. видит документ и приложенную выписку;
- сотруднику, выносящему вопрос на правление, доступны оба варианта завершения задачи.

Наличие задачи само по себе не всегда предоставляет право изменять документ или добавлять файлы, поэтому права нужно проверить отдельно.

## 12. Тестирование

### Сценарий 1 — отрицательное решение

1. Создайте тестовый документ нужного вида.
2. Запустите обработку.
3. Выполните задачу «Вынести вопрос на правление».
4. Завершите задачу с результатом `Отрицательный`.
5. Убедитесь, что задача на ознакомление создана только Санакоевой Е. Ю.
6. Убедитесь, что задачи Аветисян и Заярной не созданы.
7. Выполните ознакомление от имени Санакоевой.
8. Проверьте, что процесс завершился.

### Сценарий 2 — положительное решение

1. Создайте второй тестовый документ.
2. Выполните задачу «Вынести вопрос на правление».
3. Завершите задачу с результатом `Положительный`.
4. Убедитесь, что задача «Приложить выписку из протокола» создана Аветисян Н. В.
5. Убедитесь, что задача Санакоевой не создана.
6. Проверьте, что без выписки задачу нельзя завершить.
7. Приложите выписку и завершите задачу Аветисян.
8. Убедитесь, что только после этого создана задача на ознакомление Заярной Ю. Н.
9. Выполните ознакомление от имени Заярной.
10. Проверьте, что процесс завершился.

### Сценарий 3 — задача не завершена

1. Откройте задачу «Вынести вопрос на правление», но не выбирайте результат.
2. Убедитесь, что задача не завершается без выбора доступного результата.
3. Убедитесь, что до завершения первой задачи не создаётся ни одна из последующих задач.

## 13. Ввод в эксплуатацию

1. Назначьте сроки действий по внутреннему регламенту.
2. Выполните встроенную проверку схемы.
3. Проверьте обе ветви на тестовых документах.
4. Переведите правило в состояние `Действует`.
5. Назначьте его основным правилом обработки для вида «Материалы для правления по наградам».
6. При необходимости включите автоматический запуск.

## Контрольный чек-лист

- [ ] Дополнительный реквизит для решения не используется.
- [ ] Для задачи «Вынести вопрос на правление» доступны положительный и отрицательный результаты.
- [ ] При отрицательном решении задача на ознакомление создаётся только Санакоевой Е. Ю.
- [ ] После ознакомления Санакоевой отрицательная ветвь завершается.
- [ ] При положительном решении задача на приложение выписки создаётся только Аветисян Н. В.
- [ ] Задачу Аветисян нельзя завершить без выписки.
- [ ] Только после задачи Аветисян создаётся ознакомление Заярной Ю. Н.
- [ ] После ознакомления Заярной положительная ветвь завершается.
- [ ] До завершения первой задачи обработка не переходит ни в одну ветвь.
- [ ] Проверены права всех участников.
- [ ] Обе ветви проверены на тестовых документах.
