# Описание БП: заполнение плательщика за ТУ

## 1. Автоматическое заполнение плательщика за ТУ

Доработать автоматическое заполнение плательщика за ТУ при формировании заявки на ТС в УТ и ЕРП для сокращения времени обработки заявки и исключения ошибок при заполнении.

### 1.1. Заявки «ЦС — Покупатель» и «ПЗУ — Покупатель»

> Пункт уже реализован.

Порядок заполнения:

- При изменении способа доставки на «Наша доставка» для реквизита «Плательщик за ТУ» устанавливать значение реквизита «Контрагент», указанного в карточке организации, выбранной в заявке.
- При изменении способа доставки на «Силами клиента» для реквизита «Плательщик за ТУ» устанавливать значение реквизита «Контрагент», указанного в самой заявке.
- Если реквизит «Контрагент» в заявке не заполнен, устанавливать значение реквизита «Грузополучатель».

Для обоих типов заявок реквизит «Плательщик за ТУ» сделать недоступным для редактирования.

### 1.2. Заявки «ПЗУ — ЦС»

Порядок заполнения:

- Для реквизита «Плательщик за ТУ» устанавливать значение реквизита «Контрагент», указанного в карточке организации, выбранной в заявке.

Для данного типа заявки реквизит «Плательщик за ТУ» сделать недоступным для редактирования.

### 1.3. Заявки «Поставщик — ПЗУ/ЦС»

Реквизит «Плательщик за ТУ» не заполняется значениями по умолчанию. Реквизит остаётся доступным для редактирования и обязателен для заполнения.

## 2. Загрузка заявок из ЕРП в УАТ

При загрузке заявок на ТС из ЕРП в УАТ реквизит «Контрагент» заполнять по реквизиту «Плательщик за ТУ».
